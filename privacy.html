Information We May Process

Depending on which Azen features are enabled, Azen may process limited Discord-related information needed to provide those features.

Discord IDs Server, channel, role or user IDs where required for configuration or commands.
Configuration Server settings, feature preferences and other configuration created by administrators.
Command Data Information needed to execute a requested command or return its result.
Moderation Data Limited event or message information where an enabled moderation or security feature requires it.
